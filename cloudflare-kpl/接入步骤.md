# KPL 云函数接入

Worker 地址：https://yingdong1000days.a0777625355.workers.dev

## 1. 替换代码
Cloudflare → Workers & Pages → yingdong1000days → Edit code。
把 worker.mjs 的全部内容粘贴到主文件中，替换 Hello World，点击 Deploy。

## 2. 添加密钥
该 Worker → Settings → Variables and Secrets → Add。
类型选 Secret，名称 DEEPSEEK_API_KEY，值填你在 DeepSeek 开放平台生成的 API Key，保存/部署。
不要把密钥写进网页文件或发送到聊天。

## 3. 添加数据缓存
Cloudflare → Storage & databases → KV → Create，名称可以用 kpl-cache。
回到 Worker → Bindings → Add binding → KV namespace。
Variable name 填 KPL_CACHE，选择刚创建的 kpl-cache，保存/部署。

## 4. 设置定时更新
Worker → Settings → Trigger Events → Cron Triggers → Add。
Cron 表达式：7,37 * * * *
即每小时第 7、37 分钟更新一次。调度时区为 UTC，此表达式在北京时间也为每小时第 7、37 分钟。
新增触发器可能需要一段时间传播，然后等待一次实际运行。

## 5. 验证
访问 /health：configured 为 true 表示密钥与 KV 绑定已存在（不代表密钥已验证有效）。
访问 /api/kpl：首次更新前返回 WAITING_FOR_UPDATE，成功后包含 text、sources、fetchedAt。
最后刷新本地网站 Game 页面。网站每次加载读取云端缓存；云端每 30 分钟调用一次 DeepSeek，公开访问无法触发付费调用。
首次更新失败可查看 Worker 日志（代码只记录通用错误，不输出密钥）。

## 上线到自己的域名
当前默认允许 http://127.0.0.1:8765 和 http://localhost:8765。
部署正式网站时，在 Worker 新增 Text 变量 ALLOWED_ORIGINS，填写网站来源地址（协议+域名，不带路径），多个地址用英文逗号分隔。

## 费用与边界
Cloudflare 与 DeepSeek 分别计费；定时任务启用后即使无人打开网站，也会按时调用 DeepSeek。默认每天最多约 48 次定时尝试。如需暂停，移除 Cron Trigger 即可。
联网搜索摘要不等于官方实时比分接口；页面展示来源和更新时间，失败时保留旧资料并标注时效。
