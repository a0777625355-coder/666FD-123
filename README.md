# 我们的第 1000 天

这是一个给小栋和小颖使用的像素风纪念站，打开 `index.html` 即可运行。深蓝像素风保持不变，整体布局按新版示意图重做。

## 布局与内容

- 进入页（门禁）：LEE & CHENG 标题、距离纪念日的天数、密码＝天数，支持自定义背景大图
- 顶部标签：时光 / 吃喝 / 玩乐 / Game / 相册 / 信
- 时光：在一起计时（天/时/分/秒）、天数/小时/日落统计、巡游条、小颖七套服装换装、动作馆、日子与事件
- 吃喝：「菜单 / 奶茶」两个列表，菜名可改、喜爱程度（爱心）可打分、可增删
- 玩乐：看电影、刷抖音、看比赛、逛淘宝、刷短剧、看电视（进入选择页面）、听歌、逛街（地址＋一键打开地图）、约会（联系电话）
- Game：选游戏（王者荣耀 / 原神 / 金铲铲 / Others）→ 选角色 → 打开官网
- 相册：网页右下角添加照片、拖拽上传、点击放大左右切换
- 信：在 `js/config.js` 中编辑

## 个性化设置

编辑 `js/config.js` 中的 `myName`、`herName`、`gateTitle`、`startDate`、`subtitle`、`letter`、`passwordIsDays`、`password`、`bgImage`、`music`、`phone`、`fun`、`games`、`foodDefaults`。

照片、事件、菜单和地址保存在浏览器本地。清除浏览器缓存会丢失本机数据，请使用侧栏的“备份”保存 JSON，改电脑后“导入”。

## 观看设备

页面保留像素风主视觉，并针对桌面、平板和手机做了自适应布局：平板会收窄卡片，手机会切换为单列内容、横向导航和底部按钮。

## 本地运行

直接双击 `index.html`，建议使用 Chrome 或 Edge。

## 目录说明

网页发布版本只保留运行所需的 `index.html`、`css`、`js` 和 `assets`，以及角色设定图和使用说明。私人相册、原始设计素材和历史附件未纳入仓库。
