# 我们的第 1000 天

这是一个给小栋和小颖使用的像素风纪念站，打开 `index.html` 即可运行。

## 内容

- 首页：在一起的计时、天数、小时和日落统计
- 换装：小颖七套服装及呼吸、挥手、走路、跳跃动作（新增海边裙装）
- 动作馆：两人的动作展示
- 日子与事件、相册：在网页右下角添加并保存到当前浏览器
- 信：在 `js/config.js` 中编辑

## 本地运行

直接双击 `index.html`，建议使用 Chrome 或 Edge。

## 个性化设置

编辑 `js/config.js` 中的 `myName`、`herName`、`startDate`、`subtitle`、`letter`、`password` 和 `music`。

照片和事件会保存在浏览器本地。清除浏览器缓存会丢失本机数据，请使用网页中的“导出备份”保存 JSON。

## 目录说明

网页发布版本只保留运行所需的 `index.html`、`css`、`js` 和 `assets`，以及角色设定图和使用说明。私人相册、原始设计素材和历史附件未纳入仓库。
