我们的第 1000 天 · 使用说明
============================

一、怎么打开
  双击 index.html，用 Chrome 或 Edge 打开。
  进入页有两个口令（简易登录，身份只影响聊天）：
    输入上面的天数 → 以小颖身份进入
    输入 000       → 以小栋身份进入（可在 config.js 改 login.him）
  主页不会显示身份相关的提示。

二、打开后是什么（六个标签页 + 侧边栏）
  顶部标签：时光 / 吃喝 / 玩乐 / Game / 相册 / 信
  左侧栏（手机在顶部横排）：换装、动作的文字选项，以及备份/导入。

  时光
    大数字计时（天/时/分/秒）、在一起天数、巡游条、日子与事件。
    日子与事件是动态时间线：按年份分组，竖线有流动光点、
    节点呼吸发光、事件滚动到眼前时逐条浮现；
    还没到的日子会显示「还有 N 天」。添加事件时会一起保存。

  侧边栏 · 聊天
    「💬 聊天」进入对话界面：小颖（粉气泡）小栋（青气泡），头像用两人的像素小人。
    消息存在浏览器里，互相切换身份就能看到对方留的话；可「清空」记录。
    不同浏览器（Chrome / Edge）之间的本地数据不互通——需要互通时：
      在聊天页点「连接文件夹」，Chrome 和 Edge 都选择同一个「我们的1000天」文件夹，
      之后消息会通过文件夹里的 chat.json 互相同步（两边都不丢消息）。
    想要真正的实时同步（手机 + 电脑随时互见）：
      1. 打开 https://supabase.com 用邮箱注册一个免费账号
      2. 新建 Project（名字随意，区域选 Singapore / Tokyo，密码自己设）
      3. 左侧 SQL Editor，粘贴执行：
         create table if not exists chat (
           id text primary key, who text not null,
           text text not null, time bigint not null
         );
         alter table chat enable row level security;
         create policy chat_access on chat for all to anon using (true) with check (true);
      4. 到 Project Settings → API Keys，复制「Project URL」和「anon public」密钥
      5. 打开 js\config.js 的 cloud 块，enabled 改成 true，
         填上 url 和 anonKey，保存后 push 到 GitHub（或本地 F5 测试）
      6. 聊天页显示「实时同步 ✧」即成功；多设备打开你的域名就能实时互聊

  侧边栏 · 换装
    白卫衣 / 绿格裙 / 灰上衣 / 粉毛衣 / 女仆装 / 画家帽 / 海边裙装
    点一下立即换装。

  侧边栏 · 动作
    呼吸 / 挥手 / 走路 / 跳跃，点一下切换动作；
    「动作馆 ➜」进入下一级页面，汇总两人的所有动作和表情。

  吃喝
    分成「菜单」「奶茶」两页。
    点菜名＝改名；点爱心＝打喜爱程度；悬停出现「×」可删除；右上角「＋ 添加」加菜。

  玩乐
    左边一列：看电影 / 刷抖音 / 看比赛 / 逛淘宝 / 刷短剧 / 看电视 / 听歌 / 逛街 / 约会。
    点某一项，右边才会显示对应的选择页面：
    普通项＝直接打开对应网站；「看电视」＝选择页面
    （爱奇艺 / 优酷 / 芒果 / Bilibili）；「逛街」＝输入地址后能一键打开地图；
    「约会」＝显示联系电话，可拨打或复制。

  Game
    上排选游戏（王者荣耀 / 原神 / 金铲铲 / Others），下排选角色，
    再点「去玩」打开官网。角色名在 js\config.js 里改。

  相册
    点「＋ 添加照片」或把图片拖进虚线框；点照片可放大查看，左右切换。

  信
    正文在 js\config.js 的 letter 里改。

三、自己添加内容（不用改代码）
  右下角/侧栏一直有：
    备份       把你加过的事件、照片、菜单、地址存成 json
    导入       把备份 json 选回来
  这些内容存在这个浏览器里。清缓存会丢，请偶尔点一次备份。

四、名字和纪念日
  打开 js\config.js，改这几行：
    myName      你的名字
    herName     她的名字
    startDate   在一起那天，格式 年-月-日，例如 "2023-05-20"
    subtitle    首页大数字下面那句
    letter      最后那封信
    gateTitle   进入页大标题（默认 LEE & CHENG）
    passwordIsDays   true＝密码是到现在的天数；不想设就 false
    password    额外口令，可留空 ""
    bgImage     背景大图路径，留空用默认深蓝像素底
    music       把 mp3 放到 assets，再写文件名；没有就留空 ""
    phone       「约会」里显示的电话
    fun         玩乐那一列：名字、类型、链接、平台
    games       游戏：名字、官网链接、角色列表
    foodDefaults  刚打开时的默认菜单/奶茶（网页里可直接改）

  改完保存，浏览器按 F5。

五、小颖换衣服
  侧边栏「换装」里点文字选项即可（白卫衣 / 绿格裙 / 灰上衣 / 粉毛衣 /
  女仆装 / 画家帽 / 海边裙装），下面「动作」切换呼吸、挥手、走路、跳跃；
  点「动作馆 ➜」可以看两人的所有动作汇总。

六、不要把新照片和新事件写进 config.js 排版
  photos 请保持空数组；events 里是已经整理好的基础时间线，请保留。
  以后新增内容使用网页上的添加按钮即可。
